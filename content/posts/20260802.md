## Introduction
Before jumping into retrieval, I wanted a memory layer that behaved less like a vector database and more like the way humans connect ideas. Instead of storing isolated chunks, I built a semi-graph memory that combines semantic search with explicit relationships between concepts. The result is a system that not only remembers facts, but can also follow connections, revisit context, and retrieve information in a way that feels significantly more coherent. In this post, I'll walk through the architecture, the design decisions, and the lessons learned while building it.

You wil find original in idea on Andrej Karpathy's post [here](https://x.com/karpathy/status/2039805659525644595).
